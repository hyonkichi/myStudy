このブログについて

「My Study」は、新しい技術への挑戦や日々の気づきを記録するための個人ブログです。本業の傍ら、趣味として触れている技術についてつらつらと書き残しています。

📝 ブログのコンセプト

組み込みエンジニアとして培った経験を活かしつつ、Web技術や生成AIなど新しい分野にも挑戦する中で得た気づきやアイデアを記録していきます。完璧な記事を目指すのではなく、学びの過程そのものを残すことを大切にしています。

✍️ 書いている内容

  • 日記: 日々の出来事、気づき、学んだことなど
  • アプリ案: アプリ開発のアイデアや構想の備忘録

👤 運営者について

組み込みソフトウェアエンジニアとして10年の経験があります。普段はファームウェアやデバイスドライバの開発に携わっていますが、Web技術や生成AIの活用といった新しい領域にも強い興味を持っています。

本業とは異なる技術に触れることで視野を広げ、エンジニアとしての引き出しを増やしていきたいと考えています。

興味のある分野

  • HTML / CSS / JavaScript などのWeb技術
  • 生成AI（ChatGPT、Claude など）の活用
  • 個人開発・Webアプリケーション
  • 開発効率化・自動化ツール

🛠️ このブログの技術

このブログは以下の技術で構築されています：

  • ホスティング: GitHub Pages（無料）
  • フロントエンド: HTML5 + CSS3
  • デザイン: カスタムCSS（レスポンシブ対応）
  • バージョン管理: Git

💭 ブログを始めた理由

趣味で触っている技術について、気づきや新しいアイデアを気軽に残せる場所が欲しいと思ったからです。完成度の高い記事を書くというより、試行錯誤の過程や「これ面白いな」と思ったことをメモ感覚で記録していきます。

また、Web技術の学習も兼ねて、このブログ自体もHTML/CSSで手作りしています。
